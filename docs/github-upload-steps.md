# Upload Member 5 Documentation

1. Confirm the correct branch with the team lead. `member-5-qa-docs` was not present in the remote branch list seen earlier; `Testing-Docs` was present.
2. Open a terminal in the repository folder.
3. Copy the documentation files into the repository.
4. Check `git status`.
5. Stage the intended files, for example:
   `git add docs/requirements.md docs/permission-matrix.md docs/user-journeys.md docs/test-cases.md docs/bug-list.md README.md`
6. Commit:
   `git commit -m "docs: add initial requirements and QA documentation"`
7. Push to the confirmed branch with `git push`.
8. Open GitHub and verify the files on that branch.

Do not push directly to `main` unless the team lead explicitly asks you to.
